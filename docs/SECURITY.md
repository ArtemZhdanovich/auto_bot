# Безопасность

Модель безопасности; журнал аудитов и инцидентов — [INCIDENTS.md](../INCIDENTS.md).

## Аутентификация и авторизация

- Mini App: подпись initData (APP_SECRET_KEY) → JWT access/refresh
  (короткий access); refresh идемпотентен; гостевые сессии без
  персональных фич.
- Партнёрский кабинет: X-API-Key (hash-only в БД, ротация/отзыв),
  rate-limit; админ-контур: X-Internal-Token (в prod обязателен).
- Права в сценариях, не в транспорте: гость → 403 (чаты/анализы/
  размещения), тарифные гейты (чеки Pro+, агент/instant Business),
  владение (чужие лоты/треды → 404 без раскрытия).

## Данные и приватность

- Маскировка контактов в чатах seller/deal/group (телефоны/мессенджеры;
  наш бот и share-ссылки не трогаются), support не маскируется.
- Чаты: участники видят только свои треды (subscribe-proxy + REST);
  операторы — support; retention 90 дней после закрытия (скрытие).
- Пейролл: Stars-вебхуки идемпотентны (условный UPDATE статуса),
  уникальные ключи платежей/лидов.

## Инфраструктура

- Link-preview SSRF: только http/https, резолв всех A/AAAA-записей
  публичны, ≤1 редирект с повторной проверкой, ≤512KB, 3с, кэш 24ч.
- Upload: сниф магических байт (jpeg/png/webp), ≤8MB, uuid-ключи.
- CORS/origins Centrifugo, prod-гварды секретов (internal_token,
  centrifugo secret ≠ change-me) — tests/security.

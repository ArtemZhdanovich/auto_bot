# Навигация v4 + лендинг (решение владельца 2026-10-28)

## 1. Лендинг: всегда на «/» + быстрый вход

- Браузер, `/` без query → лендинг ВСЕГДА (даже если surface выбран);
  последняя выбранная карточка помечена «● последний вход» и стоит
  первой; клик = вход, выбор не «запирает» (Surface запоминается
  только для сортировки карточек).
- В профиле кнопка «Сменить поверхность» → сбрасывает на лендинг.
- Telegram и deep-links (/listing/N, /?make=…) — без изменений, сразу
  мини-апп. `/partner`, `/admin` — свои поверхности.

## 2. Mini App: 4 таба, без плавающих кнопок

| Таб | Контент |
|---|---|
| **Главная** `/` | лента + AI-поиск (сегмент «Лента \| AI» сверху, AI-чат как панель на том же экране), FAB «+ Продать» только здесь |
| **Авто** `/auto` | сегменты: Избранное / История (просмотры+разборы) / Мои объявления (для не-гостей) |
| **Чаты** `/chats` | текущий экран чатов целиком (сегмент Диалоги/Переговорные) |
| **Профиль** `/profile` | как сейчас (плюс «Сменить поверхность») |

- Плавающий конверт ChatEnvelopeFloat и ChatBadge в сайдбаре — удалить
  (чат — таб; бейдж непрочитанных на самом табе).
- Роуты-совместимость: /favorites /analyses /ai — редирект на новые
  (KeepAlive-набор обновить: главная с сегментом, /auto, /chats, /profile).
- Десктоп-сайдбар: те же 4 пункта.

## 3. Партнёрский кабинет: 5 табов + «Ещё»

- Таб-бар (мобайл): Обзор, Пул, Мои, Чаты, Ещё.
- «Ещё» → bottom-sheet: Рынок, Витрина, Объявления, Чеки, Биллинг
  (активный из шторки подсвечивает таб «Ещё»).
- Десктоп-сайдбар: все 9 пунктов списком (без сворачивания).
